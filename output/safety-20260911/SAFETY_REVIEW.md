## 实机验收仍缺的证据

- 当前环境缺少 DDS SDK，两个修改过的 DDS 源文件尚不能完成对应 SDK 分支编译；核心 vendor 宏仅编译验证不能替代完整 DDS 链接与部署验收。
- 本轮没有连接或运行真机；未验证实体急停线路、断能反馈、SDK 调用阻塞时的实际停机延迟、各轴制动距离及急停后的恢复流程。
- Tare 锁存入口拒绝已运行 C++ 离线回归；串口采样窗口的取消与偏置提交顺序完成源码契约检查和编译，未完成串口采样集成测试。
- 已进入 vendor SDK 的调用、已被夹爪控制器接收的运动，不能由本轮软件取消令牌保证瞬时撤回。当前夹爪驱动没有经过验证的独立硬件急停协议；取消待发命令和停止软件线程不等同于夹爪物理断能。
- 未知轴反馈继续显示未知；本轮真实点动要求明确使能反馈，因此不可读轴会被前端拒绝点动。确认保护解除依据 HAL 确认成功及新的安全锁存反馈，不能将未知轴伪造为已断使能。
- 常规断使能请求仍按同侧 HTTP 顺序处理；全局急停使用独立通道。HTTP 请求返回、UI 按钮禁用或离线测试通过均不代表设备已经停止。

完成 DDS 编译和受控实机验收前，本记录不构成正常生产运行的安全放行。
