# 相机标定操作步骤（张正友法）

工具：[`scripts/calibrate_camera.py`](../scripts/calibrate_camera.py)。只读相机画面，不驱动机械臂和夹爪。

## 适用范围

| 相机 | 方法 |
| --- | --- |
| `global`、`wrist_left`、`wrist_right`（普通镜头） | 本流程：张正友法求内参，再记录定型参考位姿 |
| 第 4 路显微成像单元（高倍或远心镜头） | 不适用。针孔模型在这类镜头下病态，改用载物台测微尺标定 µm/像素，另行处理 |

张正友法解决每路相机的**内参**：焦距 fx、fy，主点 cx、cy，畸变 k1、k2、p1、p2（k3 可选）。它本身不回答“相机装在哪里、朝向哪里、以后有没有被碰动”，所以本工具另外提供：

- `pose`：标定板放在可重复的参考位置时，记录相机相对标定板的位姿和参考画面，作为定型存档；
- `check`：之后把标定板放回同一位置，复核相机是否移动。

相机到工作原点 W 或机械臂末端的外参（手眼标定）不在本流程内。

## 0. 准备

### 标定板

- 使用棋盘格，**内角点**数一奇一偶，推荐 `9x6`，即 10×7 个方格。命令参数填的是内角点数，不是方格数。一奇一偶的板可以用颜色区分两端，参考位姿的原点每次都落在同一个物理角上。
- 尺寸：在相机工作距离下，标定板约占画面宽度的 1/3 到 1/2；每个方格在画面中至少 15–20 像素。
- 材质必须刚性、平整，用玻璃、陶瓷或铝基板；小视场用光刻玻璃板。纸打印再贴到板上只适合粗标。
- 方格边长用卡尺或显微镜**实测**后填写。它决定位姿平移的尺度，不影响内参。
- 棋盘四周至少留一格宽的白边。

### 相机

1. 按杨谢鹏的意见把安装位置和角度调到位并紧固，做好定位标记（定位销或划线）。
2. 调好焦距和光圈后锁紧（锁紧螺丝或点胶）。**调焦或变焦后内参全部作废，必须重标。**
3. 分辨率与录制一致（当前 640×480）。内参只对标定时的分辨率有效。
4. 在设置页把曝光、增益、白平衡改为手动固定值并保存。照明要充足、无频闪，标定板静止时画面清晰。
5. 确认相机身份绑定正确：设置页的全局相机身份，以及腕部相机的“识别 / 绑定”。

### 软件

- 在工控机上，从仓库根目录用后端虚拟环境运行（下文命令均为 PowerShell）。
- 默认经后端快照接口取图，所以服务需要运行，后端地址默认 `http://127.0.0.1:18082`。这样拿到的画面、身份绑定和分辨率与录制完全一致。
- 后端没运行时，可用 `--source device --index N` 直连相机。此时必须先停服务，否则相机被占用。
- 不要在录制进行中做标定。
- 结果默认保存在 `%USERPROFILE%\.appstation\camera_calibration\<相机>\`，可用 `--root` 改路径。

## 1. 采集标定图像（每路相机各做一次）

```powershell
backend/.venv/Scripts/python.exe scripts/calibrate_camera.py capture --camera global --board 9x6 --square-mm 2.5
```

窗口操作：空格保存，`A` 切换自动保存，`Q` 退出。自动保存只在标定板静止 0.4 秒、且位置和上一张明显不同时触发。窗口上的 4×4 网格中，绿格表示已有角点覆盖，红格表示还没有覆盖。

拍摄要求，共 20–30 张：

- **位置**：画面中心、四角、四条边都要有；角点要贴近画面边缘，因为畸变主要在边缘。
- **朝向**：正对 2–3 张；绕水平轴前后倾 20°–45°、绕竖直轴左右倾 20°–45° 各若干张；再加几张对角方向的倾斜。如果全部正对，焦距无法确定。
- **远近**：在景深范围内略有变化，不能出现模糊。
- **质量**：整块板都在画面内，不反光、不模糊。手持时拿稳再保存，最好用支架。

其他说明：

- 分次采集的图像会累积到同一目录。换标定板时要换 `--root` 目录，工具会拒绝把两种板混在一起。
- 腕部相机用 `--camera wrist_left` 或 `--camera wrist_right`，操作相同。
- 没有图形界面时，用 `--no-preview` 自动采集，默认 25 张，可用 `--count` 修改。

## 2. 计算内参并验收

```powershell
backend/.venv/Scripts/python.exe scripts/calibrate_camera.py calibrate --camera global
```

输出 `intrinsics.json`（内参、畸变、每张误差、覆盖率、倾斜角、相机身份）和 `undistort_check.png`（左原图、右去畸变）。命令行最后一行给出“通过”或“需复核”。

| 项 | 要求 | 不满足时 |
| --- | --- | --- |
| 重投影误差 RMS | ≤ 0.5 px（清晰图像通常 0.1–0.3） | 看 `views` 中 `errorPx` 大的图像，删掉模糊或反光的，再重拍 |
| 画面覆盖 | ≥ 75% | 补拍四角和边缘 |
| 倾斜视角 | 倾斜 ≥ 15° 的至少 3 张 | 补拍倾斜视角 |
| fx、fy 不确定度 | < 1% | 增加倾斜视角和张数 |
| 去畸变对照图 | 右图中标定板边缘、台面直线是直的 | 检查是否选错相机，或镜头是否被动过 |

- 单张误差 > 1 px 的图像会自动剔除后重算，清单见 `rejected`。
- 默认不估计 k3，因为普通视场镜头估计 k3 容易过拟合。只有明显广角（有鱼眼感）的镜头才加 `--free-k3`。
- 重复计算时，旧的 `intrinsics.json` 会自动备份为 `intrinsics.<时间>.bak.json`。

## 3. 定型：记录参考位姿

1. 做一个能重复放置标定板的定位工装（定位销、靠边或限位块），放在相机要看的工作区附近；每路相机可以各有一个参考位置。标定板在工装里的朝向每次都相同。
2. 腕部相机随机械臂运动：先在界面把双臂回到工作原点 W，以后每次 `pose` 和 `check` 都在 W 下做。
3. 运行：

   ```powershell
   backend/.venv/Scripts/python.exe scripts/calibrate_camera.py pose --camera global --note "定型日期；参与人员；标定板放置位置"
   ```

4. 输出三个文件：
   - `reference_pose.json`：位姿和参考角点；
   - `reference.png`：参考画面；
   - `reference_axes.png`：坐标轴示意。原点是外侧对角方格为黑色的那个内角点；红色 X 轴沿行方向，绿色 Y 轴沿列方向，蓝色 Z 轴垂直于板面。
5. 多帧角点抖动应 < 0.5 px。偏大说明标定板没有固定好，或者光照在闪烁。
6. 参考文件已存在时，默认拒绝覆盖。确需重新定型时加 `--force`（旧文件会自动备份），并在记录中写明原因。

## 4. 复核：定期、采集前，或怀疑相机被碰过时

1. 把标定板放回工装；腕部相机先回到 W。
2. 运行：

   ```powershell
   backend/.venv/Scripts/python.exe scripts/calibrate_camera.py check --camera global
   ```

3. 判定：
   - **通过**：最大角点偏移 ≤ 1 px，退出码 0。
   - **不通过**（退出码 1）：先重新放一次标定板再测；仍不通过，说明相机移动了。此时暂停采集，按第 3 步重新定型；如果镜头或调焦也被动过，要从第 1 步重新标内参。处理过程要记录下来。
4. 每次结果追加到 `checks.jsonl`。`check_latest.png` 上红圈是参考位置，绿点是当前位置。
5. 偏移量里也包含标定板的放置误差。如果工装重复性不够，可以用 `--max-shift-px` 放宽阈值，但要写进记录。

## 5. 归档

- 三路相机都完成后，把 `camera_calibration` 目录整体复制到共享盘或科研记录，按日期命名。
- 记录内容：参与人员、标定板规格和实测方格边长、各相机身份（见 `intrinsics.json` 的 `cameraInfo.identity`）、曝光等手动设置。

## 运行时图像校正与复核

- 三路实机镜头的身份、内参及当时的测试条件见 [2026-11-26 标定记录](camera-calibration/2026-11-26/README.md)。内参用于图像去畸变；支架和工作原点的重复性仍通过 `pose`、`check` 复核。
- 启用去畸变时，在 `cameras.lensIntrinsics` 中按角色存放通过验收的内参对象。使用 `intrinsics.json` 的 `schema`、`kind`、`camera`、`verdict`、`cameraInfo.identity`、`imageSize`、`distortionModel`、`cameraMatrix` 和 `distCoeffs`。未配置的角色输出原图。换镜头、调焦或互换同型号腕部机身后，要重新确认内参与实物对应，USB 口绑定只能识别安装位置。
- 5174 的 MJPEG 预览、普通快照和新录制共用同一套 OpenCV 去畸变几何，`alpha=0`，输出保持采集尺寸。`calibrate_camera.py` 始终通过 `snapshot?raw=true` 取得原图，以便继续使用原始角点和参考位姿。
- 数据集的 `meta/appstation_info.json` 在 `hardware.cameraRectification` 记录各路源矩阵、畸变系数及输出矩阵。已有原图数据和校正几何不同的数据需要分开建集；回放读取已保存的图像。
- 快照接口返回 JPEG 压缩画面，对角点精度影响很小；需要最高精度时，停服务后用 `--source device`。
