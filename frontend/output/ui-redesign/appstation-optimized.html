AppStation 全页面优化 前后对比

七个页面 · 一套控制台语言

在原有信息架构上统一配色与排版：冷中性纸面 + 单一操作蓝 + 语义状态色； 状态改「点 + 短标签」；数据统一等宽；急停固定为右下急停坞；底部合并为一条状态条。 下方按页面列出调整前后的差异。切换顶部「优化前 / 优化后 / 并排对比」可直接查看界面。

优化前共性问题

  • 多套浅灰蓝背景并用，卡片边框阴影堆叠
  • 状态卡左色条成排出现，条纹噪音
  • 顶栏 / 底栏信息拥挤，急停按钮悬浮漂泊
  • 图表六色与状态色语义脱节
  • 空态、危险态、表单态层级不够清晰

优化后统一策略

  • 背景 #EEF1F5，卡片白面 + 细边 + 轻阴影
  • 状态点 + 标签，仅异常态轻染底色
  • 薄仪表顶栏；单状态底条；右下急停坞
  • 操作蓝唯一强调，绿/琥珀/红只表达状态
  • 安全横幅、危险度置顶、表单分区卡片化
主页

调整前

  • 左色条状态卡四格并列
  • 双臂面板条纹噪音强
  • 缺少全局安全一眼摘要

调整后

  • 顶部 Safety 横幅 + 状态点卡片
  • 设备 chip 行 + 数值单元格
  • 力觉汇总卡与图表同层级
录制

调整前

  • 相机标题过重，FPS 色突兀
  • 运动监看信息挤成一片
  • 侧栏安全与硬件列表弱层级

调整后

  • 相机作主角，全局加宽
  • 位姿 + 轴计量 + 力觉三栏
  • 危险度置顶，硬件列表紧凑
数据集

调整前

  • 左右分栏但空态大片留白
  • 导出/保存按钮主次不清
  • 浏览器与审阅区无视觉锚点

调整后

  • 数据集列表 + 摘要条
  • 回放区三路视频 + 进度
  • 力觉曲线与质量指标并列
模型

调整前

  • 三卡同权，延迟进度条语义弱
  • Start/Stop 按钮视觉弱
  • 精度选择与状态标签脱节

调整后

  • 卡片强调延迟与就绪态
  • 主操作按钮强调色
  • 精度分段控件统一
微调

调整前

  • 表头输入框与按钮挤在标题栏
  • 空表「No data」缺少引导
  • 任务状态标签无语义色

调整后

  • 创建任务表单独立分区
  • 空态给出下一步动作
  • 状态点 + 标签 + 操作列
自动

调整前

  • 相机浅色占位发灰
  • 队列图与控制区权重失衡
  • 启动/急停按钮层级平

调整后

  • 深色相机腔体，全局加宽
  • 队列 + 指标条清晰分区
  • 主操作强调，急停进坞
设置

调整前

  • 焦点指标条信息密度高
  • 表单字段平铺无分组感
  • 安全阈值字段缺少语义

调整后

  • 四格焦点卡 + 连接状态点
  • 模块分区卡片 + 标签 Tab
  • 阈值分组，危险字段轻染
